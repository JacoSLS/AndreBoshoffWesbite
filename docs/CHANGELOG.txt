HOW TO DEPLOY A VERSION
-----------------------
A) UPDATING THE LIVE SITE  (the normal case, from v1.8 on)
   The zip is an UPDATE zip: it has no "data" folder and no uploaded photos,
   so it cannot overwrite Andre's wording, services, gallery, reviews or
   photos. Upload it as it is: cPanel > File Manager > public_html >
   Upload > Extract (overwrite) > delete the zip.
   Extracting never deletes files: the version notes below list any old
   files to delete by hand, and any wording to type in the admin.

B) FRESH INSTALL  (new host, or rebuilding from scratch)
   Take the full site from GitHub (folder site/, which includes data/) and
   follow DEPLOY-FIRST.txt.

Never upload a zip that is not in this folder. Never upload README.md,
DEPLOY-FIRST.txt or CHANGELOG.txt to the server.
